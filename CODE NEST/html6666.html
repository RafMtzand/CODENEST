Resumen de HTML

HTML es el lenguaje que usamos para estructurar páginas web. Nos permite insertar texto, imágenes, enlaces, formularios, videos y más.

Funciones Principales

  • Crear estructura para contenido web
  • Permitir navegación con enlaces
  • Insertar imágenes, videos y otros medios
  • Recolectar datos con formularios
  • Usar estilos y scripts con CSS y JavaScript

Estructura Básica

Una página HTML típica contiene las siguientes secciones:

<!DOCTYPE html>
<html>
  <head><title>Título</title></head>
  <body>Contenido visible</body>
</html>

Etiquetas Comunes

EtiquetaUso
<h1> a <h6>Títulos o encabezados
<p>Párrafos de texto
<a>Enlaces
<img>Imágenes
<ul>, <li>Listas
<table>, <tr>, <td>Tablas
<form>, <input>Formularios
