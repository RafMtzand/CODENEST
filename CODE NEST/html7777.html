Resumen de CSS

CSS (Cascading Style Sheets) es un lenguaje de diseño que permite controlar la presentación visual de documentos HTML. Separa el contenido (HTML) del estilo, haciendo posible aplicar colores, márgenes, posiciones y mucho más.

¿Para qué sirve CSS?

  • Aplicar estilos visuales como colores, fuentes, tamaños y bordes
  • Diseñar layouts responsivos (adaptables a distintas pantallas)
  • Animar elementos y crear transiciones
  • Organizar visualmente los componentes de una página

Formas de aplicar CSS

  • En línea: usando el atributo style en cada elemento
  • Interno: escribiendo CSS dentro de una etiqueta <style> en el <head>
  • Externo: vinculando un archivo .css con <link>

Ejemplo de sintaxis

selector { propiedad: valor; }
Ejemplo:
h1 { color: blue; font-size: 2em; }
