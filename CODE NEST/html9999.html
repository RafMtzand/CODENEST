Resumen de MySQL

MySQL es un sistema de gestión de bases de datos relacional de código abierto muy utilizado en entornos web. Es desarrollado por Oracle Corporation y se caracteriza por su rapidez, fiabilidad y facilidad de uso.

¿Para qué sirve MySQL?

  • Almacenar y gestionar grandes volúmenes de datos estructurados
  • Realizar consultas SQL para extraer o modificar información
  • Crear relaciones entre tablas mediante claves foráneas
  • Administrar usuarios y permisos de acceso
  • Integrarse con aplicaciones web y backend como PHP, Node.js, Python

¿Cómo funciona MySQL?

MySQL sigue el modelo cliente-servidor: los usuarios (clientes) envían solicitudes a través de sentencias SQL, y el servidor MySQL responde ejecutando operaciones sobre las bases de datos.

Ejemplo básico

CREATE TABLE alumnos (
  id INT PRIMARY KEY,
  nombre VARCHAR(100),
  edad INT
);
