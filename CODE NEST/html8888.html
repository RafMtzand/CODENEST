Resumen de JavaScript

JavaScript es un lenguaje de programación interpretado, orientado a objetos, que permite añadir interactividad y dinamismo a las páginas web. Fue creado inicialmente por Netscape y actualmente es un estándar del lado del cliente en la mayoría de los navegadores.

¿Para qué sirve JavaScript?

  • Modificar contenido de HTML y estilos (CSS) en tiempo real
  • Capturar y manejar eventos del usuario (clics, teclas, etc.)
  • Validar formularios en el navegador
  • Manipular datos y comunicarse con servidores (AJAX / fetch)
  • Crear animaciones, juegos, apps web e interfaces ricas

¿Cómo se integra JavaScript?

  • En línea: usando el atributo onclick, onchange, etc.
  • Interno: dentro de una etiqueta <script> en el documento HTML
  • Externo: mediante un archivo .js vinculado con <script src="archivo.js">

Ejemplo de sintaxis

let saludo = "Hola Mundo";
function mostrarSaludo() {
  alert(saludo);
}
mostrarSaludo();
